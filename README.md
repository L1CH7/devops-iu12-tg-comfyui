## 3. Чек-лист выполненных этапов инфраструктуры
- [x] **Настройка окружения и связности**: Настройка IP-адресов, Caddy Proxy и mesh-сети Yggdrasil на ПК1 для внешнего доступа.
- [x] **Сборка и развертывание заглушек**: Созданы Multi-stage Docker-образы для `server-api` и `tg-bot` на базе `uv` и Python.
- [x] **Автоинициализация PostgreSQL**: Автоматический накат DDL-схемы ([init-db.sql](compose/pc1-server/init-db.sql)) со структурой таблиц пользователей, сценариев и генераций.
- [x] **Автосоздание бакетов MinIO**: Инициализационный контейнер `minio-init` для автоматического создания публичного бакета `generations` в S3.
- [x] **Приоритетная очередь в Redis**: Конфигурация Redis ZSET для управления приоритетом обработки запросов (VIP-пользователи обходят очередь обычных).
- [x] **Инфраструктурные Smoke-тесты**: Скрипт [test_infra.py](tests/test_infra.py) проверяет доступность TCP-портов и готовность HTTP-эндпоинтов на ПК1 и ПК2 (включая проверку моделей ComfyUI).
- [x] **Интеграционные E2E-тесты**: Скрипт [test_e2e.py](tests/test_e2e.py) сквозного тестирования БД, Redis, MinIO S3 и API ComfyUI.
- [x] **Сбор логов и метрик (Observability)**: Promtail собирает логи контейнеров и отправляет их в Loki на ПК2; Prometheus собирает аппаратные и контейнерные метрики через Node Exporter.
- [x] **Автоматический CI/CD пайплайн**: Настроен GitHub Actions workflow ([deploy.yml](.github/workflows/deploy.yml)) для параллельного деплоя на self-hosted раннерах ПК1 и ПК2 с запуском Smoke и E2E тестов после развертывания.

## 5. Быстрый запуск

### Основной сервер (ПК1):
```bash
cd compose/pc1-server
cp .env.example .env
# Отредактируйте .env и укажите пароли
docker compose up -d --build
```

### Сервер мониторинга (ПК2):
```bash
cd compose/pc2-monitor
cp .env.example .env
# Отредактируйте .env
docker compose up -d --build
```
*Подробности конфигурирования и проверки работоспособности читайте в **[Руководстве администратора](docs/admin-guide.md)**.*
