# Руководство пользователя (User Guide)

Данный документ описывает возможности Telegram-бота для генерации изображений с использованием искусственного интеллекта (ComfyUI / Stable Diffusion) и правила взаимодействия с ним.

---

## 1. Запуск бота и авторизация

Для начала работы с ботом:
1. Перейдите по ссылке на бота в Telegram (или найдите его по имени пользователя, настроенному администратором).
2. Нажмите кнопку **Запустить** (или отправьте команду `/start`).
3. Бот автоматически зарегистрирует вас в системе и выдаст стартовый баланс генераций.

---

## 2. Основные возможности и команды

### Генерация изображений
Для генерации картинки просто отправьте боту текстовое описание (промпт) на английском языке.
* *Пример:* `A futuristic cyberpunk city with neon lights, flying cars, high detailed, 8k resolution`

### Негативный промпт (Negative Prompt)
Вы можете указать, какие элементы вы **не хотите** видеть на сгенерированном изображении (например, размытость, дефекты анатомии, текст). Для этого используется специальный синтаксис (или интерфейсная кнопка в зависимости от версии бота).
* *Пример:* `beautiful landscape --no blur, low quality, ugly, cartoon`

### Получение информации о профиле
Команда `/profile` (или соответствующая кнопка меню) позволяет узнать:
* Ваш текущий статус (Обычный пользователь / VIP-пользователь).
* Оставшееся количество генераций на сегодня.
* Время окончания кулдауна (если действует ограничение).

---

## 3. Тарифные планы и Лимиты

В системе действует разделение пользователей на роли для эффективного распределения ресурсов GPU-сервера:

| Параметр / Роль | Обычный пользователь (`user`) | VIP-пользователь (`vip`) |
| :--- | :--- | :--- |
| **Дневной лимит** | 10 генераций | 100 генераций |
| **Кулдаун между запросами** | 60 секунд | 5 секунд |
| **Приоритет в очереди** | Обычный | **Высокий (VIP)** |

### Как работает VIP-очередь?
Когда вы отправляете запрос, он помещается в единую очередь генерации на сервере приложений (база данных Redis). 
* Запросы VIP-пользователей автоматически обходят запросы обычных пользователей и выполняются в первую очередь.
* Обычные пользователи обрабатываются по принципу "первым пришел — первым обслужен" (FIFO), но только при отсутствии VIP-запросов в очереди.

---

## 4. Возможные проблемы и их решение

1. **Бот долго не отвечает на запрос генерации**
   * *Причина:* Очередь на сервере перегружена (большое количество VIP-запросов) или GPU-сервер занят обработкой сложной генерации.
   * *Решение:* Подождите немного или проверьте статус очереди (если бот предоставляет такую команду). Ваша задача обязательно выполнится.

2. **Бот пишет "Превышен лимит генераций"**
   * *Причина:* Вы исчерпали свой дневной лимит (10 для обычных или 100 для VIP).
   * *Решение:* Лимит сбрасывается каждые 24 часа. Либо обратитесь к администратору для повышения вашей роли до VIP.

3. **Бот пишет "Пожалуйста, подождите X секунд"**
   * *Причина:* Сработал кулдаун-таймер защиты от спама (60 секунд для обычных пользователей).
   * *Решение:* Подождите указанное время перед отправкой следующего промпта.
